# Niko's Home Assistant Addons

Custom addons for Home Assistant.

## Installation

1. Go to **Settings → Add-ons → Add-on Store**
2. Click **⋮** (top right) → **Repositories**
3. Add: `https://github.com/nikopolv/ha-addons`
4. Click **Add** → **Close**
5. Refresh and find the addons

## Available Addons

### Memos

Open-source, self-hosted note-taking tool built for quick capture.

- **Markdown-native** — Full Markdown support
- **Lightweight** — ~20MB, SQLite storage
- **Timeline UI** — Open, write, done
- **Self-hosted** — Your data stays on your HA
